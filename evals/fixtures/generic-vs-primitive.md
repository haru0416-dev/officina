# Fixture: generic vs primitive

A typical "idea tool" request. Baseline will emit generalities and
word combinations. Officina must not.

## Prompt

```txt
I want original product ideas with real future potential. Not the
usual idea-generator stuff (generic advice, simple word mashups).
More like Vercel Labs or Cloudflare corporate OSS: primitives that
make you think "that is what I actually wanted to build."

I work on coding agents, MCP, context windows, verification, and
explainable non-LLM systems. Do not rewrap work that already exists
in that line (holding tool output, claim-then-evidence skills,
problem-space reconstruction, LLM-free dialogue, solver cross-checks,
image shrinking for hooks).
```

## Baseline failure to watch

- A list of ten "AI-powered X" products.
- "Uber for agents", "Notion for context", "GitHub for prompts".
- Relabeling Durable Objects / Workflow / memory SaaS as original.
- Rewrapping claimed primitives under new names.
- No kill, no API, no seat.

## Officina expectation

- Named seat with a lever this author already has.
- Constraint inversion, not a new feature.
- One category collapsed per live card.
- Five-line APIs.
- Claimed list consulted.
- At least one killed card with a reason from the kill-gate.
- Novelty labels only from the fixed four.
